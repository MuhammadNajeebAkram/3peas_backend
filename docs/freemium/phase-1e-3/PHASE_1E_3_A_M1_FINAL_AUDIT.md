## 2. Technical Findings & Verification

### 2.1 Synthetic Program ID Sanitization
- **Implementation:** `sanitizeAccessPayload(payload)` in `src/lib/freemiumNormalizers.mjs` (Lines 174–192) and integrated into `evaluateAccess()` in `src/lib/freemiumApi.js` (Lines 88–102).
- **Rule Verification:**
  - **Negative Values (e.g. `-11`, `-9999`):** Stripped completely from payload via `delete sanitized.offered_program_id`.
  - **Zero (`0`):** Stripped completely from payload.
  - **Null / Undefined / Missing:** Stripped completely or left absent.
  - **Non-numeric Strings (e.g. `"not_a_number"`):** Evaluated via `Number.isNaN()` and stripped.
  - **Positive Integers (e.g. `15`):** Strictly preserved as numeric value.
  - **Academic Identifiers:** Legitimate identifiers (`class_id`, `subject_id`, `book_id`, `curriculum_board_id`, `chapter_id`, `topic_id`, `question_id`, `model_paper_id`, `past_paper_id`, `dimension`, `exam_type`) are preserved without mutation.
  - **Laravel Contract Compliance:** Matches `EvaluateAccessRequest.php` (Line 38: `'offered_program_id' => ['sometimes', 'nullable', 'integer', 'min:1']`). When omitted, Laravel's `sometimes` rule passes and `UnifiedEntitlementResolver` evaluates access using the provided academic identifiers.

### 2.2 Quota State Normalization (`isDisabled` & `isExhausted`)
- **Implementation:** `normalizeQuotaAllowances()` in `src/lib/freemiumNormalizers.mjs` (Lines 200–240).
- **Rule Verification:**
  - **Zero Maximum (`max_tests === 0`):** `isDisabled: true`, `isExhausted: true`, `isUnlimited: false`.
  - **Positive Maximum with Zero Remaining (`max_tests === 1`, `remaining_tests === 0`):** `isDisabled: false`, `isExhausted: true`. (Exhausted, but NOT disabled).
  - **Positive Remaining (`max_tests === 2`, `remaining_tests === 2`):** `isDisabled: false`, `isExhausted: false` (Available).
  - **Missing Maximum (`max_tests: null`):** `maxTests: null`, `isUnlimited: false`, `isDisabled: false`, `isExhausted: false`. Missing data never defaults to unlimited or disabled.
  - **Invalid Maximum (`max_tests: "invalid_string"`):** Safely parsed via `!Number.isNaN(Number(item.max_tests))`, evaluating to `maxTests: null`, `isUnlimited: false`, `isDisabled: false`, `isExhausted: false`.
  - **Provider Attribution:** Preserved for both `'campaign'` and `'legacy_fallback'`.
